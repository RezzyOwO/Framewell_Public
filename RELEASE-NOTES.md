# Framewell 0.14.0

## A quieter workspace
- GIF editing uses a lightweight live preview. Encoding starts only when you open Export.
- Progress appears in a compact corner card with a spinner, progress bar, and Cancel.
- Inspect the actual first and last GIF frames in Export with Loop boundary.

## Start fresh, save deliberately
- Framewell opens with a clean workspace, without a recovery popup.
- Closing an unsaved project offers Save, Don't save, or Cancel.
- Recover your previous workspace from the File menu when needed.
- Automatic installation waits until your project is saved.

## Gallery and export folders
- Gallery rows fill the available width and balance portrait and landscape photos.
- Sharper thumbnails stay cached; selections still work across month folders.
- Default photo exports go into Pictures/Framewell Pictures/YYYY-MM.
- GIF exports go into Videos/Framewell Videos/YYYY-MM. Custom destinations remain unchanged.

## Support the creator
- A fixed Patreon card sits below each sidebar's scrolling controls.
- Open it to see the current public profile, banner, membership plans, and available member counts.
- Profile information refreshes automatically and stays available offline.

## Also included since 0.10.1
- Resizable sidebars, clearer enabled toggles, a File menu, and a dedicated photo-history sidebar.
- Visual photo, GIF and platform presets; Discord and X/Twitter export, including both formats at once.
- Seamless-loop controls, live speed/reverse/ping-pong playback, better zoom navigation, and a photo filmstrip.
- Improved caption controls, automatic sizing, custom text layers, background bars and color pickers.
- Remembered watermark placement, export summaries, recent destinations, and a one-time update changelog.

## Download
Windows x64. Download [Framewell-Installer-Win.exe](https://github.com/RezzyOwO/Framewell_Public/releases/download/v0.14.0/Framewell-Installer-Win.exe).

The versioned Framewell-0.14.0-Setup.exe is identical and supports automatic updates. Settings and projects are preserved. Versions 0.9.1 and 0.10.0 need a manual installer run once to repair their old update launcher.

Validation: 75 native tests passed, desktop workflows checked, and the packaged app verified for save-on-close, manual recovery, export-only GIF encoding, and monthly export destinations.
