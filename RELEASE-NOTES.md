# Framewell 0.10.0

## Watermarks and gallery

- Improved watermark color handling and preview quality, including sharper text watermark previews.
- Uploading a watermark enables it for every photo. New photos inherit the selected watermark while keeping their own positioning controls.
- VRChat Gallery detects VRChat's configured photo folder and redirected Windows Pictures folders, including other drives. Onboarding and Settings include a Detect button; manually selected folders stay selected.

## GIF captions and presets

- Turning uppercase off now preserves lowercase text, including when the previous font only contains capital-shaped letters.
- Added full-width text fitting, left/center/right alignment and independently adjustable top and bottom caption bars.
- Customize bar color, opacity, height and padding alongside font, size, outline and spacing.
- Save your own GIF recipes and caption styles. Recipes remember canvas and encoding settings; caption styles keep the text you are currently editing. Photo looks and export recipes remain available separately.

## A cleaner workspace

- GIF export preparation shows a blurred preview, rotating loading icon, rendering progress, Cancel and Retry. Leaving export stops its active GIF render.
- Fixed recovery button spacing and help tips being clipped by panels.
- Release notes expand without a nested scrolling box. Encoding and advanced caption controls can be collapsed.

The installation-folder fixes from 0.9.1 are included. Original media and saved projects remain untouched during installation.

Windows x64. Download [Framewell-Installer-Win.exe](https://github.com/RezzyOwO/Framewell_Public/releases/download/v0.10.0/Framewell-Installer-Win.exe) to install Framewell.

The versioned `Framewell-0.10.0-Setup.exe` download is an identical copy used by the automatic updater.
